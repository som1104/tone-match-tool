# 톤 매칭 이미지 보정 툴 (프로토타입)

레퍼런스 이미지를 기준으로 여러 장의 이미지 톤을 자동으로 맞춰주는 웹 툴입니다. 모든 처리는 브라우저 안에서(Canvas + WebGL) 이루어지며, 서버로 이미지를 업로드하지 않습니다.

## 시작하기

```bash
npm install
npm run dev
```

`http://localhost:3000` 접속.

## 주요 기능

- **톤 매칭** — 레퍼런스 이미지 기준으로 LAB 색공간에서 Reinhard 평균/표준편차 매칭, 히스토그램 매칭, MKL(공분산 기반) 매칭 중 선택. 이미지별로 색상/명암 강도를 개별 조정 가능
- **영역별 분리 매칭** — 비교 화면을 클릭해 색상 유사도 기반으로 영역을 선택(마술봉 방식)하고, 선택 영역과 나머지를 서로 다른 강도로 조정. 허용 범위·가장자리 부드럽게(feather) 조절 가능
- **마무리 효과** — 색수차, 소프트 글로우, 대비, 컬러 틴트, 질감(필름 그레인 / 종이 / 망점) 등 모든 이미지에 공통 적용되는 후처리. WebGL 셰이더로 슬라이더 조작 시 실시간 반영
- **프리셋** — 마무리 효과 설정을 이름 붙여 저장하고 다시 불러오기
- **되돌리기 / 다시 실행** — 작업 내용을 자동으로 기록해 언제든 이전 상태로 복귀
- **세션 자동 저장 · 이어하기** — 업로드한 이미지와 설정을 브라우저에 자동 저장해두고, 다음 방문 시 배너로 이어할지 새로 시작할지 선택
- **다크 모드** — 정색 작업 시 주변 밝기에 따른 색 인지 왜곡을 줄이기 위한 어두운 테마
- **색상 분포 히스토그램** — 원본과 보정 결과의 R/G/B 채널 분포를 막대그래프로 비교
- **스포이드** — 이미지 위 클릭으로 해당 지점의 색상 코드(hex) 복사
- **원본 해상도로 보기** — 세로로 긴 웹툰형 이미지도 모달에서 원본 해상도로 확대 확인
- **일괄 처리 · ZIP 다운로드** — 여러 이미지에 기본 강도를 일괄 적용하고, 각자의 조정값 그대로 한 번에 압축 다운로드

## 구성

### lib/

- `colorTransfer.ts` — LAB 색공간 변환 및 톤 전사 알고리즘 (Reinhard 평균/표준편차 매칭, 히스토그램 매칭, MKL 매칭)
- `glBlend.ts` — WebGL 셰이더 렌더러. 원본과 매칭 결과를 LAB 공간에서 블렌딩하고, 영역 마스크 기반 분리 강도, 마무리 효과, 영역 경계 표시까지 실시간으로 처리. 슬라이더 조작 시 uniform만 갱신하므로 재계산 없이 반응
- `regionMask.ts` — 클릭 지점 기준 색상 유사도로 영역을 찾는 플러드필(마술봉), 가장자리 페더링, 다운로드용 원본 해상도로 마스크 확대
- `export.ts` — 다운로드 시 미리보기와 동일한 셰이더로 원본 해상도 결과물 렌더링
- `palette.ts` — 이미지에서 대표 색상 팔레트 추출 (16 / 32 / 64개 선택 가능)
- `presets.ts` — 마무리 효과 설정을 이름 붙여 저장/불러오기 (localStorage)
- `sessionStore.ts` — 업로드 이미지·설정을 저장해 새로고침 후에도 이어서 작업할 수 있게 함 (IndexedDB/localStorage)
- `image.ts` — 이미지 로딩(EXIF 방향 보정 포함), 리사이즈, Canvas 변환 등 유틸리티
- `dnd.ts` — 드래그 앤 드롭으로 들어온 파일 중 이미지 파일만 필터링

### components/

- `Sidebar.tsx` — 레퍼런스 업로드(클릭/드래그 앤 드롭), 알고리즘 선택, 팔레트(클릭 시 색상 코드 복사), 일괄 처리·ZIP 다운로드, 다크모드 토글
- `CompareStage.tsx` — 레퍼런스/결과(또는 마무리 효과의 적용 전/후) 패널을 나란히 배치하고 스크롤 동기화, 레이아웃 계산
- `ResultPanel.tsx` — WebGL 캔버스에 실시간 렌더링, 스포이드, 영역 선택 클릭, 전후비교 슬라이더
- `StrengthPanel.tsx` — 색상 전사 강도 / 명암 휘도 강도 슬라이더. 영역별로 나눠 보정, 밝기 양 끝 보호는 팝오버로 제공
- `FinishingPanel.tsx` — 색수차·글로우·대비·틴트·질감 조절, 프리셋 저장/적용 팝오버
- `Popover.tsx` — 버튼을 누르면 뜨고 바깥을 클릭하거나 Esc를 누르면 닫히는 팝업 카드. 화면 밖으로 잘리지 않도록 위치를 자동 계산
- `ColorHistogram.tsx` — 원본/보정 결과의 R/G/B 채널 분포 비교 막대그래프
- `ColorPickerTooltip.tsx` — 스포이드로 읽은 색상 정보를 커서 옆에 표시
- `ZoomModal.tsx` — 원본 해상도로 확대해서 보는 모달 (세로로 긴 이미지 확인용)
- `FilmStrip.tsx` — 오른쪽 세로 썸네일 목록(클릭/드래그 앤 드롭 업로드 가능). "개별 조정됨"과 "전체 적용 기준"을 동시에 표시
- `SliderRow.tsx` — 라벨이 붙은 슬라이더 공통 컴포넌트

## 사용 흐름

1. 좌측에서 레퍼런스 이미지 업로드 (자동으로 팔레트 추출)
2. 오른쪽 필름스트립에 보정할 이미지 여러 장 업로드
3. 알고리즘 선택 후 "일괄 처리" — 전체 이미지에 기본 강도로 우선 적용
4. 필름스트립에서 이미지를 클릭해 크게 보면서 색상/명암 강도를 조절 (조절한 값은 그 이미지에만 적용됨). 인물과 배경처럼 부분적으로 다르게 조정하고 싶으면 "영역별로 나눠 보정"에서 영역을 선택 후 각각 강도 지정
5. 다른 이미지들도 이 값으로 통일하고 싶으면 "이 값을 전체에 적용"
6. "마무리 효과" 탭에서 색수차·글로우·대비·틴트·질감 등 전체 공통 후처리 적용 (자주 쓰는 조합은 프리셋으로 저장해 재사용)
7. 사이드바에서 ZIP 일괄 다운로드 (각 이미지는 저장된 자기 강도값으로 내보내짐)

작업 중 실수했다면 되돌리기/다시 실행으로 이전 상태로 돌아갈 수 있고, 브라우저를 껐다 켜도 "이어하기" 배너를 통해 작업을 이어갈 수 있습니다.

## 알려진 한계

- 영역 선택은 색상 유사도 기반 플러드필 방식이라, 배경과 색이 비슷한 인물 영역은 한 번에 깔끔하게 분리되지 않을 수 있음 (허용 범위·가장자리 조정 또는 여러 번 클릭으로 보완)
- 조명 방향/구도가 크게 다른 이미지 간에는 색상은 맞아도 부자연스러울 수 있음
- 클립스튜디오 등 레이어 기반 제작 툴에 직접 연동되는 프로덕션 툴이 아니라, 최종 결과물이 평면 이미지면 충분한 용도(이커머스, 마케팅, 사진 보정 등)를 타겟으로 함
- 모든 처리가 브라우저에서 이뤄지므로, 매우 큰 이미지나 다량의 이미지를 한 번에 처리하면 기기 성능에 따라 느려질 수 있음
