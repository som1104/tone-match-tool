# 톤 매칭 이미지 보정 툴 (프로토타입)

레퍼런스 이미지를 기준으로 여러 장의 이미지 톤을 자동으로 맞춰주는 웹 툴입니다. 모든 처리는 브라우저 안에서(Canvas + WebGL) 이루어지며, 서버로 이미지를 업로드하지 않습니다.

## 시작하기

```bash
npm install
npm run dev
```

`http://localhost:3000` 접속.

## 구성

- `lib/colorTransfer.ts` — LAB 색공간 기반 Reinhard 평균/표준편차 매칭, RGB 히스토그램 매칭 알고리즘 (알고리즘 자체는 CPU에서 1회 계산)
- `lib/glBlend.ts` — WebGL 셰이더. 원본과 매칭 결과를 LAB 공간에서 명암(L)과 색상(A, B)을 독립적으로 블렌딩. 슬라이더를 움직일 때마다 uniform만 갱신하므로 재계산 없이 실시간으로 반응
- `lib/export.ts` — 최종 다운로드 시 미리보기와 동일한 셰이더로 원본 해상도 결과물을 렌더링
- `lib/palette.ts` — 이미지에서 대표 색상 팔레트 추출 (16 / 32 / 64개 선택 가능)
- `lib/dnd.ts` — 드래그 앤 드롭으로 들어온 파일 중 이미지 파일만 필터링
- `components/Sidebar.tsx` — 레퍼런스 업로드(클릭/드래그 앤 드롭), 알고리즘 선택, 팔레트(클릭 시 색상 코드 복사), 일괄 처리·ZIP 다운로드
- `components/CompareStage.tsx` — 레퍼런스와 보정 결과를 나란히 비교하는 화면. 뷰포트에 맞춰 스크롤 없이 유동적으로 채워짐
- `components/StrengthPanel.tsx` — 색상 전사 강도 / 명암 휘도 강도 슬라이더, 현재 이미지 값을 전체에 적용하거나 기본값으로 되돌리는 버튼
- `components/FilmStrip.tsx` — 오른쪽 세로 썸네일 목록(클릭/드래그 앤 드롭 업로드 가능). 클릭하면 해당 이미지가 비교 화면에 로드됨. "개별 조정됨"(점)과 "전체 적용 기준"(배지)을 동시에 표시

## 사용 흐름

1. 좌측에서 레퍼런스 이미지 업로드 (자동으로 팔레트 추출)
2. 오른쪽 필름스트립에 보정할 이미지 여러 장 업로드
3. 알고리즘 선택 후 "일괄 처리" — 전체 이미지에 기본 강도(70/70)로 우선 적용
4. 필름스트립에서 이미지를 클릭해 크게 보면서 색상/명암 강도를 조절 — 조절한 값은 그 이미지에만 적용됨
5. 다른 이미지들도 이 값으로 통일하고 싶으면 "이 값을 전체에 적용"
6. 개별 조정을 취소하고 싶으면 "기본값으로"
7. 사이드바에서 ZIP 일괄 다운로드 (각 이미지는 저장된 자기 강도값으로 내보내짐)

## 알려진 한계

- 이미지 전체를 대상으로 톤을 매칭하며, 인물/배경 영역별 분리 매칭은 아직 미구현
- 조명 방향/구도가 크게 다른 이미지 간에는 색상은 맞아도 부자연스러울 수 있음
- 클립스튜디오 등 레이어 기반 제작 툴에 직접 연동되는 프로덕션 툴이 아니라, 최종 결과물이 평면 이미지면 충분한 용도(이커머스, 마케팅, 사진 보정 등)를 타겟으로 함
